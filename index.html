              Import & export

              Paste a playlist link on its own line — a YouTube playlist (youtube.com/playlist?list=…), a SoundCloud set (soundcloud.com/artist/sets/…) or a public Spotify playlist (open.spotify.com/playlist/…). You can also paste many song links, one per line, or the names of songs.

              Check which songs play

              YouTube does not publish which videos block playback in other apps, so the only way to know is to try each one. This plays every YouTube song in your queue silently for a few seconds and marks the ones that refuse. It takes a while on a long queue, and you'll hear nothing while it runs.
